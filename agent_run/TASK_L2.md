## 背景

Heisenberg（交换）相互作用作用在两个量子比特 a, b 上为
H_ab = X_a X_b + Y_a Y_b + Z_a Z_b。
已知结论（Cubitt, Montanaro, Piddock, PNAS 115, 9497 (2018)）：耦合强度可调的 Heisenberg 模型是一个通用哈密顿量，借助编码和微扰 gadget，可以在低能子空间中模拟其他局域哈密顿量。但“通用”是关于低能谱的陈述，并不直接意味着它的动力学难以经典模拟。
