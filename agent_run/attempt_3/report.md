## 1. 路线选择

### 1.1 采用的路线

- 目标选用**静态、常数时间的对易（IQP 型）Ising 动力学**。静态哈密顿量在固定时间 t = π 的演化就是一个 IQP 电路，不需要任何时间控制的逻辑门序列，正适合“只用 Heisenberg 项的静态 H_sim”这个设定。
- 对易目标有一个好处：只要 H_eff 精确对角，所有误差都只是相位误差，不会出现非对易误差导致的态泄漏。我们找到了一种块内守恒量，使 H_eff **精确**对角（C1）。
- 困难性方面，我们没有使用平均情形的猜想（BMS 2016 的 Conjecture），而是用**最坏情形、无猜想**的 #MONOTONE-2SAT（Valiant 1979）。通过一个精确的 Z_4 相位 gadget（C7），把计数结果写成一个逻辑振幅。再利用“重复子句不改变计数、但改变归一化”这一自由度，使加性误差 c·2^{−n} 足以恢复精确的计数值。

### 1.2 考虑过但放弃的路线

| 路线 | 放弃原因 |
|---|---|
| 直接套用 Cubitt–Montanaro–Piddock 的通用性链条（编码 + 多级微扰 gadget 模拟任意局域 H） | 多级 gadget 让 J_max 随层数复合增长（每层都要 Δ_{k+1} ≫ Δ_k^{O(1)}）。它们的结论是关于低能谱的，并不给出动力学困难性。目标是非对易的通用哈密顿量时，还需要处理非对角误差和泄漏。 |
| 同一 4 自旋码，但用一般的块间键（例如让 pair(0,2) 等参与耦合） | 会同时产生 X_L 分量（X_iX_j、Z_iX_j），破坏对易性。三阶项 λ³/Δ² 存在，导致 ε ∝ Δ^{−1/2}。 |
| 3 体目标：度数为 3 的 F_2 多项式 IQP（CCZ 型，BMS 2016 Conjecture 3） | 需要逻辑 3 体项，只能来自三阶微扰（λ³/Δ²），J_max 和误差都更差；平均情形的困难性还要依赖猜想。 |
| 随机完全图 Ising，ω = e^{iπ/8}（BMS 2016 Conjecture 2） | 平均情形 #P-hard 只是猜想，达不到本任务“已证明”的要求。完全图有三角形，三阶不消失，ε ∝ Δ^{−1/2}（见 §5 的三角形对照组，p = −0.506）。 |
| 先 #2SAT 构造 y_j·C_j(x)（每子句一个辅助比特，精确的 2^m·#SAT） | 需要 3 体项 y x_a x_b。我们改用 2 个辅助比特、只含 2 体项的 Z_4 gadget（C7），代价是每子句的归一化因子 1/2，而这一点可以被子句重复完全吸收。 |

| 物理（计算）基读出 | 已证明在单块上不可行（C11，§6.2），所以选逻辑基。 |

## 2. 编码与 gadget 推导

### 2.1 块与码空间

块内物理位点编号 0, 1, 2, 3（全局编号为 4i + a）。记 H_ab = σ_a·σ_b。块哈密顿量取
H_blk = Δ Σ_{a<b} H_ab = Δ[2S(S+1) − 6]，
所以 S = 0 的能量为 −6Δ（2 重），S = 1 为 −2Δ（9 重），S = 2 为 +6Δ（5 重），能隙是 4Δ。码空间就是 S = 0 子空间：

- |0_L⟩ = |s⟩_{01}|s⟩_{23}（两个二聚体单态）
- |1_L⟩ = (|t₊t₋⟩ + |t₋t₊⟩ − |t₀t₀⟩)/√3（两个三重态耦合成的单态）

在码空间上（已数值核对）：

- P H_01 P = P H_23 P = −I − 2Z_L；
- P D·D P = 8I + 4Z_L，其中 D = σ_0 − σ_1。

### 2.2 守恒量与 H_eff 的精确对角性 — C1 **[已证明]**

H_sim 由以下几部分组成：
- 块内 Δ Σ H_ab，它是 S_tot² 的函数；
- γ_i H_23，它是 S_23² 的函数；
- 块间项，只作用在每块的位点 0、1 上：D_i·D_j = Σ_α (σ_{i0}^α − σ_{i1}^α)(σ_{j0}^α − σ_{j1}^α)。

S_23²（每块 pair(2,3) 的总自旋）与上述每一项都对易：
- 与 S_tot² 对易，因为 S_tot² = S_01² + S_23² + 2S_01·S_23，而 S_23² 与 S_23 的各分量都对易；
- 与 H_23 对易是显然的；
- 与只作用在位点 0、1 上的算符也对易。

所以 n 个守恒量 S_23^{(i)²} 把希尔伯特空间分成 2^n 个扇区之外再加其余部分。码态 |x⟩（x ∈ {0,1}^n）中，x_i = 0 ⟺ S_23^{(i)} = 0，即逻辑 Z_i 恰好就是这个守恒量。

在每个扇区 x 内，H_0 的最低态唯一（就是 |x⟩），能隙 4Δ。最低 2^n 个本征态因此是每个扇区各取一个基态，记为 |x̃⟩。

直接旋转 U = √((2P−1)(2P_0−1)) 与所有守恒量对易，因为 P 和 P_0 都与它们对易。于是 H_eff 与所有 Z_i 对易，即**严格对角**，对角元为 E_x = 扇区 x 的基态能量。

**[数值]** n = 3 时 H_eff 的非对角元 ≤ 1e−9，这在 Δ = 10⁵ 时的舍入噪声量级内。

### 2.3 场项是精确的 — C2 的一部分 **[已证明]**

γ_i H_23 在扇区内是常数：S_23 = 0 时取 −3γ_i，S_23 = 1 时取 +γ_i。所以它对 E_x 的贡献精确等于 −γ_i − 2γ_i z_i（z = ±1 是 Z_L 的本征值），并且不改变任何能量分母。

### 2.4 二阶有效耦合 — C2 **[已证明]**

键 V_ij = λ D_i·D_j 作用在 |x⟩ 上：D^α 是矢量算符，会把块从 S = 0 激发到 S = 1（且只能到 S = 1，因为 pair(2,3) 的 S_23 不变）。所以中间态的能量**恰好**高 8Δ，场项又不改变分母。

不同键产生的中间态彼此正交（被激发的块对不同），所以二阶只有“同一条键往返”的贡献。利用 P D^α D^β P = (δ_{αβ}/3)·P D·D P（S = 0 子空间上的 Wigner–Eckart 定理）：

H^{(2)}_{ij} = −(λ²/8Δ)·(1/3)·(8 + 4Z_i)(8 + 4Z_j) = −(λ²/24Δ)(64 + 32Z_i + 32Z_j + 16 Z_iZ_j)。

由此：
- Z_iZ_j 系数为 −(2/3)λ²/Δ，取 λ_ij = √(3|J_ij|Δ/2) 即得 J_ij（要求 J_ij < 0，见 §4.3）；
- 每条边给两端各 −2|J_ij| Z 场，用 γ_i = −h_i/2 − Σ_j |J_ij| 补偿。

物理键的写法：λ(H_{i0,j0} − H_{i0,j1} − H_{i1,j0} + H_{i1,j1})。最大物理耦合是块内的 Δ（pair(2,3) 上是 Δ + γ_i）；块间耦合只有 O(√Δ)。

### 2.5 奇数阶在二部图上消失 — C3 **[已证明]**

块 A 内的置换 U_A = SWAP(0,1)：
- 保持块内项与 H_23 不变；
- 把 D_A 变成 −D_A，即所有与 A 相连的键反号；
- 在码空间上作用为 −Z_A（因为 pair(0,1) 的单态是反对称的）。

直接旋转具有协变性，所以 H_eff(λ_A → −λ_A) = Z_A H_eff Z_A = H_eff，最后一步用到 C1 的对角性。

若逻辑图是二部图，对其中一侧的所有块同时施加 U，则每条键恰好反号一次。因此 E_x(λ) = E_x(−λ)，所有奇数阶为零，误差首项为四阶 λ⁴/Δ³ = O(1/Δ)。

对照：三角形图中每个块被触及两次，三阶项存活，ε ∝ Δ^{−1/2}（**[数值]** 拟合指数 −0.506）。

## 3. 误差分析与 J_max(n)

记 |E| 为逻辑边数，|J| ≤ 3/8。已知：
- ‖D_A·D_B‖ = 4√3（数值精确值）；
- ‖V‖ ≤ 4√3·Σλ_e ≤ 3√3|E|√Δ。

### 3.1 定理（C4）**[已证明]**

若 Δ ≥ 13.5|E|²，则 ε := min_c‖H_eff − H_target − c‖ ≤ 228|E|⁴/Δ。

**证明。** 固定扇区 x，令 H(s) = H_0 + sV，其中 s ∈ ℂ。

1. 扇区内能隙为 4Δ。在以 E_x(0) 为圆心、半径 r = 2Δ 的圆周 Γ 上，‖(H_0 − z)^{−1}‖ = 1/(2Δ)。当 |s|‖V‖ < r 时 Neumann 级数收敛，所以 Γ 内恰有一个本征值 E_x(s)，它关于 s 解析，并满足 |E_x(s) − E_x(0)| < r（Kato）。
2. 由 C3，E_x(s) 是 s 的偶函数。
3. 令 g(s) = E_x(s) − E_x(0) − e₂s²，其中 e₂ 是精确的二阶系数（§2.4），|e₂| ≤ ‖V‖²/8Δ ≤ 3.375|E|²。
4. 在 |s| = R := r/‖V‖ ≥ 2√Δ/(3√3|E|) 上，|g| ≤ r + R²|e₂|。对偶函数用 Cauchy 估计，得
   |g(1)| ≤ (r + R²|e₂|)·R^{−4}/(1 − R^{−2})。
   当 R² ≥ 2（即 Δ ≥ 13.5|E|²）时，|g(1)| ≤ 2(‖V‖⁴/r³ + |e₂|‖V‖²/r²) ≤ 2(91.1 + 22.8)|E|⁴/Δ。
5. 由 §2.3–2.4，E_x(0) + e₂ = E^target_x + C₀，其中 C₀ 与 x 无关。再结合 C1 的对角性，ε ≤ max_x |g_x(1)|。∎

**[数值]** 实际系数远小于这个上界：
- n = 2：ε = 5.29·J²/Δ；
- 链 n = 2…5：ε·Δ ≈ (0.08–0.12)×键数（见 §5），随键数线性增长。

**[猜想]** ε = O(|E|/Δ)。依据是 Bravyi–DiVincenzo–Loss（Ann. Phys. 326, 2793 (2011)）的 linked-cluster/局域 SW 理论：只有连通团簇有贡献，四阶团簇是单键和两键路径。我们没有给出严格常数。

### 3.2 从 ε 到输出振幅 **[已证明]**

**缀饰码协议**（逻辑基 = 直接旋转后的码 T|x⟩）：
A = 2^{−n}Σ_x e^{−iπE_x}，所以 |A − e^{−iπC₀}A_id| ≤ πε。

**裸码协议**（C10，正文默认）：制备裸码态 |+_L⟩^{⊗n}，突然接通 H_sim，在裸码的逻辑 X 基测量。不同的 x 属于不同的守恒扇区，所以
A_bare = 2^{−n}Σ_x ⟨x|e^{−iHt}|x⟩ = 2^{−n}Σ_x [f_x e^{−iE_x t} + r_x]，其中 f_x = |⟨x|x̃⟩|²，|r_x| ≤ 1 − f_x。
因此 |A_bare − A| ≤ 2η，η := max_x(1 − f_x)。

η 的界：⟨x|V|x⟩ = 0，所以 ‖(H − E_x)|x⟩‖ ≤ √2‖V‖，而扇区内到其余谱的距离 ≥ 4Δ − 2‖V‖ ≥ 2Δ（当 ‖V‖ ≤ Δ，即 Δ ≥ 27|E|²）。由 Davis–Kahan 得 sin²θ_x ≤ ‖V‖²/(2Δ²)，即 η ≤ 13.5|E|²/Δ。

**[数值]** n = 4、5 的端到端计算中，η 与振幅误差都 ∝ 1/Δ（§5）。

合计：δA ≤ πε + 2η ≤ 744|E|⁴/Δ。

### 3.3 J_max(n) **[已证明上界]**

§4.4 将说明，困难性需要 δA ≤ Q/8，其中 Q = 2^{−v−m/2} ≥ 2^{−n/2}（因为 m ≥ v）。所以只要

Δ ≥ 5952·|E|⁴·2^{n/2}（这已经蕴含 Δ ≥ 27|E|²）。

困难族中 |E| = 4m ≤ 2n，所以 **J_max(n) = Δ ≤ 9.6×10⁴·n⁴·2^{n/2} = O(n⁴·2^{n/2})**。若 C6 的猜想成立，则 J_max = O(n·2^{n/2})。

最大块间耦合是 O(2^{n/4}·poly(n))；物理比特数 4n；演化时间 π。

### 3.4 为什么是 2^{n/2} 而不是更低 **[猜想]**

判据要求 |p_phys − p_id| ≲ c·2^{−n}。在**不做 padding** 的族中，困难概率处在自然量级。本族 m = v + K 时 p_id = #φ²·2^{−(n−K)}，恢复整数计数所需的振幅分辨率是 Q = 2^{−(n−K)/2}。一个 1/Δ 阶、一般非零的对角误差（§5 显示其中含 ZZZ 等无法用二体项补偿的项）会使振幅移动 Θ(poly(n)/Δ)，而我们没有理由期待它恰好小于 Q。因此本方案需要 Δ ≳ 2^{n/2}/poly(n)。

更一般地，若某个 gadget 达到 ε ∝ Δ^{−k}，所需 Δ 约为 2^{n/(2k)}。要把四阶的 3 体路径项也消掉、达到 k ≥ 2，是一个开放方向（§6.4）。

### 3.5 单独列出：padding 带来的“形式上的”改进（不作为主结果）

判据中的容差 c·2^{−n} 随**总**逻辑比特数 n 收缩，但真正需要的振幅精度只由核心实例决定（δA ≤ Q/8，Q = 2^{−v−m/2}）。所以可以人为加大 n 而不改变物理难度：

- **(a) 重复子句。** 取 m ≫ v（例如 m = v²），则 v + m/2 = n/4 + 3v/4，J_max = 2^{n/4 + O(√n)}。
- **(b) 加入空闲逻辑比特。** 空闲比特既无耦合也无场，|+⟩ → |+⟩ 的概率恒为 1，所以 A 不变，n 增大。容差条件只需 P + m ≥ v + 6 + log₂c。取 P = poly(s)（s = v + m 是核心规模），得到 J_max = 2^{O(s)} = 2^{O(n^δ)}，对任意 δ > 0 都成立。

这两种做法**按字面意义满足判据**（**[已证明]**，证明与 §4.4 相同）。但它们只说明“随着 n 增大判据变强”，并不是物理代价的真实降低：被估计的概率远大于 2^{−n}，padding 部分是确定性的。

因此我们不把它们作为主结果。主结果取最小 padding（m = v + K）的自然族，此时 p_id 处在 2^{−n} 的自然量级，J_max = Θ̃(2^{n/2})。评审若认可字面判据，可以把 (b) 视为一个可选的、单独列出的结论。

## 4. 困难性归约链

### 4.1 困难源 **[已发表定理]**

#MONOTONE-2SAT：给定单调 2-CNF φ = ∧_{j=1}^m (x_{p_j} ∨ x_{q_j})（v 个变量），计算满足赋值数 #φ。它是 #P-complete 的（L. G. Valiant, *The complexity of enumeration and reliability problems*, SIAM J. Comput. **8**(3), 410–421 (1979)）。#φ 也等于图 G = (V, {p_j q_j}) 的独立集数。

### 4.2 子句 gadget — C7 **[已证明]**

对每个子句引入两个逻辑辅助比特 w_{j1}, w_{j2}，令
G(x, w) = Σ_j [w_{j1}(2 + x_p + x_q) + w_{j2}(1 − x_p − x_q)] mod 4。

穷举 (a, b) 的四种取值：

| (a, b) | 第一个因子 1 + i^{2+a+b} | 第二个因子 1 + i^{1−a−b} | 乘积 |
|---|---|---|---|
| (0,0) | 0 | 1 + i | 0 |
| (1,0) | 1 − i | 2 | 2√2e^{−iπ/4} |
| (0,1) | 1 − i | 2 | 2√2e^{−iπ/4} |
| (1,1) | 2 | 1 − i | 2√2e^{−iπ/4} |

所以 Σ_{x,w} i^{G} = (2√2 e^{−iπ/4})^m·#φ。

G 只含 w–x 两体项和单体项，因此逻辑相互作用图是**二部图**（变量比特 | 辅助比特），满足 C3。

### 4.3 映射成 Ising 动力学（IQP）— C8 **[已证明]**

令 x_k = (1 − z_k)/2，z_k 为 Z_L 的本征值。

- 对 x_ix_j 的系数 a：(πa/2)·x_ix_j = (πa/8)(z_iz_j − z_i − z_j + 1)；
- 对 x_i 的系数 b：(πb/2)·x_i = (πb/4)(1 − z_i)。

于是 i^{G(x)} = e^{iθ₀}·e^{−iπE(z)}，其中
E(z) = Σ J_ij z_iz_j + Σ h_i z_i，J_ij = −a_ij/8，h_i = Σ_j a_ij/8 + b_i/4（这些系数可以模 2 约化）。

a ∈ {1, 3} 给出 J ∈ {−1/8, −3/8}，全部为负，正好是 gadget 能产生的符号。

因为 |+^n⟩ = 2^{−n/2}Σ_z|z⟩，
⟨+^n|e^{−iπH_target}|+^n⟩ = 2^{−n}Σ_z e^{−iπE(z)} = e^{iφ₀}·2^{−n}(2√2)^m #φ = e^{iφ₀}·#φ·Q，Q = 2^{−v−m/2}，n = v + 2m。

所以 p_id = #φ²·2^{−2v−m}。

**[数值]** 300 个随机实例（n ≤ 18）的核对误差为 2×10^{−16}。

### 4.4 加性误差 c·2^{−n} 足以恢复计数 — C9 **[已证明]**

固定任意常数 c > 0。若 m < v + K（K := max(0, ⌈log₂c⌉ + 6)），就重复第一个子句直到 m = v + K。重复子句不改变 #φ，n 仍是 poly 规模。

设 p̃ 满足 |p̃ − p_phys| ≤ c·2^{−n}。利用 |√a − √b| ≤ √|a − b|，以及 |√p_phys − √p_id| ≤ |A_phys − A_id| = δA：

|√max(p̃, 0) − #φ·Q| ≤ √(c·2^{−n}) + δA。

- 由 m ≥ v + 6 + log₂c，有 c·2^{−n} ≤ Q²/64，所以第一项 ≤ Q/8；
- 由 §3.3 的 Δ 选取，δA ≤ Q/8。

因此 |√p̃/Q − #φ| ≤ 1/4 < 1/2，#φ = round(√p̃·2^{v+m/2}) 精确成立（见 scheme.py 的 `count_from_estimate`）。

**结论。** 若存在经典（随机）算法，能以 ≥ 2/3 的概率把 p_phys 估计到 ±c·2^{−n}，则调用一次即可以 ≥ 2/3 的概率计算 #MONOTONE-2SAT。所以该估计问题在 BPP 归约下是 #P-hard 的（#P ⊆ FBPP^O）。

归约本身是确定性的多项式时间映射：φ → (instance, Δ(n), t = π)，外加一次舍入。

### 4.5 归约各步汇总

| 步骤 | 内容 | 状态 |
|---|---|---|
| (i) | #MONOTONE-2SAT 是 #P-complete | Valiant 1979 |
| (ii) | φ 加重复子句，计数不变 | 平凡 |
| (iii) | 计数 = Z_4 相位和（C7） | 已证明 |
| (iv) | Z_4 相位和 = 逻辑 IQP 振幅（C8） | 已证明 |
| (v) | 逻辑 IQP = H_sim 在码空间上的有效动力学，振幅误差 ≤ 744\|E\|⁴/Δ（C1–C4、C10） | 已证明 |

### 4.6 与 IQP 文献的关系

我们的目标属于“复温度 Ising 配分函数 = IQP 振幅”的框架：
- Bremner, Jozsa, Shepherd, Proc. R. Soc. A **467**, 459 (2011)；

## 6. 局限与开放问题

### 6.1 已满足的标准

在**逻辑基**下（裸码 |±_L⟩ 测量），给出了无猜想的最坏情形 #P-hard 证明，满足加性 c·2^{−n} 的判据，且 c 可以是任意常数。

### 6.2 物理基（单独列出）

**命题 C11 [已证明]：** 4 自旋单态子空间中不存在两个正交态在计算基下支撑不相交。

证明：单态在计算基下的振幅满足 α(b) = α(b̄)，且三类振幅之和为零。若两个正交态支撑不相交，可推出其中一个为零。

所以一次计算基测量无法确定性地读出逻辑比特，本文**不声称**物理基下的困难性。

再看计算基测量实际对应什么：串 0011 / 1100 投影到 |1_L⟩；0101 等投影到 Bloch 圆上与 Z 轴成 60° 的逻辑态。所以物理基概率对应“末端在 60° 旋转基测量”的 IQP 变体，其困难性是开放问题。

如果允许先做逻辑单比特门（DiVincenzo 等人在 Nature 408, 339 (2000) 中的交换门脉冲序列）再做 pair(0,1) 的单态–三重态读出（Pauli 自旋阻塞），就回到了本文的逻辑基情形。但这需要时变控制，超出了“静态 H_sim”的设定。

### 6.3 制备与测量

我们**假设**能理想地制备裸码态 |+_L⟩ = (|s s⟩ + |tt⟩)/√2，并在 {|±_L⟩} 基测量（逻辑基操作）。

态制备或测量的误差 δ_SPAM 会以 O(n·δ_SPAM) 的量级进入 δA，所以同样需要 ≲ 2^{−n/2}。这是任何以加性 2^{−n} 为判据的最坏情形困难性陈述都会面临的要求，不是本方案特有的。

### 6.4 开放问题

- **把 J_max 降到 2^{n/(2k)}（k ≥ 2）。** 单键的 1/Δ 项是对角 2 体项，可以通过把 λ²、γ 写成 Δ(μ₀ + μ₁/Δ + …) 的级数逐阶抵消。但两键路径上的 3 体 ZZZ 项（≈ 0.023/Δ）和次近邻 ZZ 项无法这样抵消，需要新的抵消机制。
- **把 J_max 的严格多项式因子 n⁴ 降到 n。** 需要严格的 linked-cluster 常数（BDL 2011 的局域 SW 理论）。
- **平均情形版本。** BMS 型的反集中 + 平均情形猜想可以给出采样困难性，但本文刻意不依赖任何猜想。
- **有界度。** Dyer–Greenhill（Random Struct. Alg. 17, 260 (2000)）给出有界度图上独立集计数的 #P-hardness，Greenhill（Comput. Complex. 9, 52 (2000)）给出最大度 3 的情形。用它们可以让逻辑度数有界（本文的结论并不依赖这一点）。
