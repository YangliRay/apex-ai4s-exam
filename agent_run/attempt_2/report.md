## 1. 编码

- 每块 4 个比特的总自旋 S=0 子空间是 2 维的。取其中两个正交态：
  |ss⟩ = singlet(01)⊗singlet(23)，|tt⟩ = [triplet(01)⊗triplet(23)]_{S=0}。
- 逻辑基：|0_L⟩ = (|ss⟩+|tt⟩)/√2，|1_L⟩ = (|ss⟩−|tt⟩)/√2。于是 X_L = |ss⟩⟨ss| − |tt⟩⟨tt|。
- 在 S=0 空间上，S₄ 作用于 [2,2] 不可约表示，其中 Klein 群平凡作用，因此 SWAP_01 = SWAP_23 = −X_L。
- 由 H_ab = 2·SWAP_ab − 1 得 H_23|_code = −1 − 2X_L。

## 3. 推导

**能隙。** Σ_{a<b∈块} H_ab = 2S² − 6，对 S=0,1,2 分别为 −6,−2,6。所以块基态就是编码空间，
单块激发能隙 4Δ，两块同时到 (1,1) 的激发能为 8Δ，到 (2,2) 为 24Δ。

**二阶微扰。** 一阶项 PVP = 0（矢量算符在单态之间的矩阵元为零）。由于 VP 完全落在 (1,1) 扇区，
H⁽²⁾ = −(1/8Δ)PV²P = −(g²/24Δ) O_A⊗O_B，其中
O_A = P(σ₀−σ₁)²P = 8 + 4X_A，O_B = P(σ₄+σ₅)²P = 4 − 4X_B。
由此得到 H⁽²⁾ = −2K − K X_A + 2K X_B + K X_A X_B。这里取 G = g²/Δ = 3K/2，使 XX 系数恰为 K。

**精确对称性（关键）。** V 只作用在 0,1,4,5 上，H₀ 是块 Casimir。因此 S_23²、S_45²、S_67² 与总自旋都守恒，
而逻辑 X_A、X_B 正是 S_23²、S_67² 在编码空间上的标签。由此可得：
1. 直接旋转与这些守恒量对易，H_eff 严格是 a + bX_A + cX_B + dX_AX_B，其对角元就是 H_sim 的精确低能本征值。
2. W = J'_23 H_23 + J'_67 H_67 与 H₀+V 严格对易，且在每个扇区上为常数，所以它的贡献精确等于 PWP。
   因此误差与 h 无关。

**各扇区精确能量（相对 H₀ 基态，不含 W）。**
- 当 x_B = +1 时，pair45 处于单态，S_45 = 0，于是 V ≡ 0，E = 0（两个扇区都是）。
- 当 x_A = +1、x_B = −1 时，问题化为二能级：E₂ = 4Δ − √(16Δ²+32g²)。
- 当 x_A = −1、x_B = −1 时，S_tot=0 的扇区有 4 个态 a(0)、b₀(8Δ)、b₁(8Δ)、c(24Δ)，以 b₀ 为中心构成星形耦合。
  约化矩阵元用 6j 符号计算，结果为 u1² = 32g²/3，u2² = 8g²，u3² = 40g²/3。
  核对：Σ = 32g² = ⟨b₀|V²|b₀⟩；各块的求和规则 4+12+20 = 36、2+3/2+5/2 = 6 均成立。

**误差。** 由久期方程展开：
- δ₂ = E₂ + 4G = 2G²/Δ − 2G³/Δ² + …
- δ₄ = E₄ + 4G/3 = −G²/(27Δ) + O(Δ⁻²)

由此 ε = (δ₂ − δ₄)/2 = (55/54)G²/Δ = (55/24)K²/Δ ≈ 1.4136/Δ（K = π/4）。

耦合图是二部树，g → −g 是相似变换，所以本征值只含 G/Δ 的整数幂，不存在 Δ^{-1/2} 项，p = −1。
用纯张量方法也能独立看出这一点：三阶项 ∝ ε_{αβγ} 收缩，而 (σ₀−σ₁)·[(σ₀−σ₁)×(σ₀−σ₁)] = 0。

**其他能隙。** 非单态以及更高的扇区位于 ≥ 4Δ − O(√Δ) 处。例如 Δ=100 时 g ≈ 10.9，下一个能级约在 3×10² 量级，
远高于 O(1) 的低能带。

import numpy as np, scheme
X=np.array([[0,1],[1,0]],complex); Y=np.array([[0,-1j],[1j,0]]); Z=np.diag([1.,-1.]).astype(complex)
def op(P,s,n=8):
    out=np.array([[1.]],complex)
    for k in range(n): out=np.kron(out,P if k==s else np.eye(2))
    return out
S=[[op(P,k) for P in (X,Y,Z)] for k in range(8)]
def eps(K,h,D):
    H=np.zeros((256,256),complex)
    for t in scheme.build(K,h,D):
        a,b=t["sites"]; H+=t["J"]*sum(S[a][i]@S[b][i] for i in range(3))
    B=scheme.code_basis(); C=np.kron(B,B)
    E,U=np.linalg.eigh(H); V=U[:,:4]
    u,_,wh=np.linalg.svd(V.conj().T@C); W=u@wh          # 直接旋转（极分解）
    Heff=W.conj().T@np.diag(E[:4])@W
    I=np.eye(2); Ht=K*np.kron(X,X)+h[0]*np.kron(X,I)+h[1]*np.kron(I,X)
    ev=np.linalg.eigvalsh(Heff-Ht); return (ev[-1]-ev[0])/2
K=np.pi/4; h=np.random.randn(2)
Ds=np.logspace(2,5,7); es=[eps(K,h,D) for D in Ds]
print(es, np.polyfit(np.log(Ds),np.log(es),1)[0], 55*K**2/24/Ds)
