方案已经完成，并按评测流程做了独立复算。误差 ε(Δ) 随 1/Δ 下降，claims.json 里声明的指数是 p = −1。

**编码：** 每块 4 个比特，取总自旋为 0 的那个 2 维子空间。|−⟩ 是两个单态的乘积 |s⟩₀₁|s⟩₂₃，|+⟩ 是两个三重态合成的总自旋 0 态，|0_L⟩、|1_L⟩ = (|+⟩ ± |−⟩)/√2。这样选基，块内交换比特 0 和 1（SWAP₀₁）在码空间上恰好就是逻辑 X。

**耦合（共 14 条键）：**

* 每块内部 6 对键都加 Δ 作为惩罚项，把态压在码空间里，能隙为 4Δ。
* 逻辑场：J₀₁ 额外加 (h₁ + K/2)/2，J₄₅ 额外加 (h₂ + K/2)/2。
* 块间：J₀₄ = +√(3KΔ)，J₁₅ = −√(3KΔ)。二阶微扰正好给出 K X₁X₂ − (K/2)(X₁ + X₂)，多出来的单比特项由上面的 +K/2 抵消。

**为什么是 1/Δ 而不是 1/√Δ：** 同时交换四对比特（0↔1、2↔3、4↔5、6↔7）会把块间耦合整体变号，而这个操作在码空间上是恒等。因此有效哈密顿量对块间耦合强度是偶函数，按普通估计会出现的 Δ^{−1/2} 项严格为零。

**复算结果：**

* 指数：K = π/4、Δ ∈ [10², 10⁵]、随机 h ∈ [−5, 5]² 时，拟合得到 p ∈ [−1.001, −0.999]，ε 严格单调下降。
* 两种实现一致：直接旋转用极分解和矩阵平方根两种方法分别算了一遍，结果一致。
* 系数 A：ε ≈ A(h)/Δ，h = 0 时 A ≈ 0.22，|h| ≤ 2 时 A ≲ 1。A 随 h 变化，所以 claims.json 没有填单一的 error_prefactor，而是在 C6 里给出了 A(h) 的公式，与实测相符到约 10⁻⁴。

**已证明与仅数值支持：**

* 已证明：编码和能隙、二阶项正好是目标、奇数阶为零。三者合起来给出 ε = O(1/Δ)。这一结论的前提是微扰级数收敛，粗略估计 Δ ≳ 10³ 时可以保证。
* 仅数值支持：
  * Δ 在 10² 到约 10³ 这一段的表现；
  * p 恰好等于 −1（即 1/Δ 系数不为零）；
  * A(h) 公式里的分数系数（13/48 等）是从数值识别出来的，没有解析推导。

**假设：** 方案要求 K ≥ 0（题目 K = π/4）。K < 0 时需要改块间耦合的符号，上面的对称性就不成立了，误差指数不再有保证。
