## 背景

Heisenberg（交换）相互作用作用在两个量子比特 a, b 上为
H_ab = X_a X_b + Y_a Y_b + Z_a Z_b。
已知结论（Cubitt, Montanaro, Piddock, PNAS 115, 9497 (2018)）：耦合强度可调的 Heisenberg 模型是一个通用哈密顿量，借助编码和微扰 gadget，可以在低能子空间中模拟其他局域哈密顿量。

## 目标

两个逻辑量子比特上的 Ising 型哈密顿量
H_target = K X_1 X_2 + h_1 X_1 + h_2 X_2，  K = π/4，h_1, h_2 为任意 O(1) 实数。

## 约束

1. 共 8 个物理量子比特：逻辑比特 1 编码在物理比特 0–3（块 A），逻辑比特 2 编码在物理比特 4–7（块 B）。
2. 物理哈密顿量只能是 Heisenberg 项的线性组合：H_sim = Σ_bonds J_ab H_ab。不允许任何其他类型的项（单比特场、ZZ、XX 等都不行）。常数项无关紧要，不需要写。
3. 方案依赖一个能量尺度参数 Δ（Δ → ∞ 时模拟应当越来越精确）。

## 你需要设计

- 每个块的编码：一个 2 维子空间，以及其中的有序正交基 (|0_L⟩, |1_L⟩)，逻辑 X、Z 按这组基定义。
- 全部物理耦合 J_ab 作为 K, h_1, h_2, Δ 的函数。
